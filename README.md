# Eden's Flower Garden

## Version 1.0

Eden's Flower Garden is a cozy c++ farming simulator game where the player helps Eden the Frog grow a garden, discover plants, and earn coins.

The goal of this project was to create a simple but complete farming game using structs, arrays, functions, file handling, and game loops.

##  Features:
- Welcome Screen
- New Game / Load Game System
- Main Menu System
- Game Loop
- Coin System
- 10 Slot Garden
